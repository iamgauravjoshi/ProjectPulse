# Future features

The MVP prioritizes canonical state, transcript ingestion, evidence-backed events,
deltas, governance, conflicts, and explicit human confirmation. These extensions
are deferred until that workflow is reliable and tested.

| Idea | Potential outcome |
| --- | --- |
| Project drift | Compare current state with the original scope, launch and cost baseline |
| Project knowledge graph | Connect requirements, decisions, tasks, dependencies, milestones and risks |
| Impact propagation | Trace how a proposed change affects security, testing, cost and launch |
| Meeting coverage gaps | Surface unresolved project items before the conversation ends |
| Decision expiry | Add review dates for temporary decisions |
| Supersession history UI | Display chains of replaced decisions without losing source evidence |
| Async sources | Ingest Teams/Slack messages, email, PR discussions and issue comments through adapters |
| MCP server | Expose scoped state/search/decision/commitment/conflict tools after auth and review boundaries exist |
| Multi-project dependencies | Detect shared blockers with explicit access checks |
| Detector packs | Add focused security, compliance, architecture, finance and delivery checks |

Live meeting capture, optional task sync and pre-meeting briefs remain lower
priority than the core delta/review demo. Complex administration, billing, native
apps, custom models, generic workflow builders and distributed infrastructure
remain outside the hackathon scope.
